## Goal
Start publishing articles on doza.ai, styled like the Anthropic newsroom (anthropic.com/news), in Doza's own look. First post targets IBC 2026 weekend traffic: "sovereign AI for media" done locally on a Mac with NVIDIA Parakeet, no GPU rack, no cloud, no metering.

## Facts used in the article (verified in this repo)
- Transcription: `mlx-community/parakeet-tdt-0.6b-v2` via parakeet-mlx on Apple Silicon (`parakeet_worker.py`).
- Story analysis: local Gemma 4, hardware-tiered from `gemma4:e2b` (8.4 GB) to `gemma4:31b` (19 GB) (`model_config.py`).
- Cloud APIs (Anthropic/OpenAI) are opt-in with the user's own key; footage never goes to Doza servers (README).
- Core is MIT, commercial Mac app adds multi-interview and press-ready features.
- "Since day one" was phrased as local-since-day-one; the codebase also references a Whisper path.

## What could not be done from the cloud session
- doza.ai and anthropic.com are blocked by the sandbox's network policy, so the live site's real palette/fonts were never seen. Style was lifted from the app stylesheet instead.
- No Claude Design "doza.ai style" project could be synced (needs `/design-sync` in an interactive session).
- No browser or Netlify API access. Deploy is still manual.

## Deploy (Netlify, logged in on Chrome)
- Drag-and-drop site: put `site/news/` next to the site's `index.html`, drag the whole site folder onto Netlify Deploys. Dropping only `news/` would replace the site.
- Git-connected site: copy `site/news/` into that repo's publish directory and push, or add that repo to a Claude session and open a PR.
- Local Claude Code on the Mac can do this with Chrome access; check out the branch and say "deploy site/news to the doza.ai Netlify site".
