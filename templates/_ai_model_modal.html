{# AI Model modal, shared by the dashboard, the project page and collections. Three modes, picked by how it is opened: - openAIModelModal(projectId): the project's own provider chooser (Local, Anthropic, OpenAI). The choice is stored on that project only. - openAIModelModal(null, { collection: slug }): the collection's chooser. A cloud provider is offered only when every member interview already uses it (Rule 3). - openAIModelModal() on the dashboard: "AI setup", API keys and the local model size only. Where AI runs is never chosen app wide. Per-variant estimates reflect the full analysis time for the project when one is known; otherwise a generic per-call estimate. On successful model switch, if the current page has an ``#analyzeBtn`` (the project view does; the dashboard doesn't), the modal triggers a re-fetch of its estimate and repaints the badge live — no reload needed. #}
