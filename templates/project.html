One-time DaVinci Resolve setup

Resolve needs External Scripting enabled so Doza Assist can auto-import timelines.

  1. Open DaVinci Resolve.
  2. Press ⌘+, for Preferences.
  3. Click the System tab at the top.
  4. Pick General from the left sidebar.
  5. Set External scripting using to Local.
  6. Click Save, then quit and reopen Resolve.

On Resolve Free, import the highlighted XML manually:

  1. Switch to DaVinci Resolve.
  2. Open File → Import → Timeline… (or press ⇧⌘I).
  3. Pick the highlighted .fcpxml file in Finder.
  4. Leave "Automatically import source clips into media pool" checked and click OK.
  5. The timeline imports and your source media links automatically — clips come in online with per-clip audio.

Doza Assist writes the source media's real path and its embedded start timecode into the FCPXML, so Resolve relinks the clips to your footage automatically on import. Dragging the .fcpxml into the Media Pool doesn't work — Resolve treats it as a media file rather than a timeline; File → Import → Timeline is the supported route. (If a clip ever shows offline because the media moved, right-click it → Relink and point at the source file.)

Your export is already in Finder — drop it into Resolve's Media Pool if you'd rather skip auto-import this time.
